Система управления задачами и мероприятиями для студенческого медиа-объединения. Платформа создана для координации работы творческих команд и организации событий различного уровня.

## Основные возможности:

-   **Управление мероприятиями**: Создание событий трех уровней (институтский, университетский, межвузовский) с автоматическим подсчетом сроков и статусов
-   **Ролевая модель**:
    -   Администраторы: полный доступ к системе
    -   Фотографы: управление задачами по съемке
    -   Копирайтеры: работа с текстовым контентом
    -   Дизайнеры: задачи по графическому оформлению
-   **Типизированные задачи**: Создание персональных и групповых задач с отслеживанием состояний выполнения
-   **Интеграция с VK**: Автоматические уведомления через VK Bot API о новых задачах и изменениях статусов
-   **Файловый менеджер**: Загрузка и управление файлами и изображениями для каждой задачи
-   **Система аудита**: Логирование всех действий пользователей для контроля изменений
-   **Чаты мероприятий**: Встроенная система обмена сообщениями для командной работы
-   **JWT аутентификация**: Безопасная система авторизации с ролевым доступом
